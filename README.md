# Telão

Compartilhamento de tela entre amigos, direto no navegador (Chrome ou Edge).

**Abrir:** https://llmartinsll04.github.io/telao/

1. Coloque seu nome.
2. Em **+ criar sala**, digite um nome e aperte Enter.
3. Clique em **Convidar** e mande o link para os amigos.
4. Cada um clica em **Compartilhar tela**; para ver alguém, **Assistir transmissão**.

A voz fica no Discord. O vídeo vai direto entre os navegadores (WebRTC); a
conexão inicial usa relays públicos Nostr pela biblioteca Trystero (MIT, ver `vendor/`).
